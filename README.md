# University Campus Navigator

A lightweight campus wayfinding starter app for a university project. It includes:

- A searchable building list
- A simple campus map overview
- Route summary output
- Mobile-friendly layout

## Local development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm run dev
   ```
3. Open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## OpenCode worktree

This repository is ready to be used as the working folder for an OpenCode agent or local coding assistant.

- Repository path: `./`
- Suggested working directory: your local clone of this repo
- Use this folder as the model worktree root when you want the agent to edit and iterate on the app.

## Notes

The project is intentionally simple and intentionally easy to extend with:

- real campus map data
- student-friendly search filters
- building detail pages
- route optimisation logic
- location-based markers
- backend integration for a full app
